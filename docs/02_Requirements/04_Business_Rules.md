# Business Rules

| ID | Rule |
|---|---|
| BR-0001 | Average cost is weighted by quantity. |
| BR-0002 | Commission is included in acquisition cost. |
| BR-0003 | Sales reduce holdings using weighted average cost. |
| BR-0004 | Portfolio valuation uses latest available market price. |
| BR-0005 | Each operation belongs to exactly one broker account. |
